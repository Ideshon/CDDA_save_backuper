# CDDA Save Backuper

Версия: `2026-06-02-r6`

Локальный менеджер сохранений Cataclysm: Dark Days Ahead / Bright Nights.

## Запуск

Windows:

```bat
run_windows.bat
```

Linux:

```bash
chmod +x run_linux.sh
./run_linux.sh
```

Или напрямую:

```bash
python cdda_save_backuper.py
```

## Где хранятся настройки программы

Настройки и заметки хранятся рядом с программой:

```text
_cdda_save_backuper_data/config.json
_cdda_save_backuper_data/_cdda_save_notes.json
```

Старый конфиг из `%USERPROFILE%\.cdda_save_backuper\config.json` программа читает только для миграции.

## Основные функции

- выбор папки `save` CDDA;
- выбор папки бэкапов;
- выбор/автопоиск исполняемого файла игры;
- запуск игры из программы;
- список сохранений со столбцами: сохранение, дата изменения, размер, количество файлов, заметка;
- бэкап активного или выбранного сохранения;
- копирование, переименование и безопасное удаление сохранений;
- восстановление выбранного backup;
- заметки к сохранениям;
- лог справа;
- режим тестирования модов: зафиксировать выбранное сохранение и откатить его после закрытия игры.

## Режим тестирования модов

1. Выбери сохранение.
2. Нажми `Включить` в блоке `Тест модов: откат после закрытия игры`.
3. Запусти игру.
4. Тестируй моды.
5. Закрой игру.
6. Программа восстановит сохранение к исходному состоянию.

Если процесс игры не найден, впиши точное имя `.exe` в поле `Процессы игры` или выбери файл игры через `Обзор`.
